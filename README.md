# DEVIANTS_Safetrack-AI

## Video Understanding & Temporal Reasoning

The full-stack video analysis application is in [`video-understanding/`](video-understanding/README.md).
It includes a React/TypeScript frontend, a FastAPI backend, actual video upload and URL ingestion,
chunked vision-model analysis, entity tracking, interactive event timelines, and timestamped temporal
question answering. Existing SafeTrack modules remain in their original directories.

See the [setup guide](video-understanding/README.md), [validation report](video-understanding/VALIDATION.md),
and [real-video evaluation protocol](video-understanding/EVALUATION.md). Install the configured Ollama
vision model before analysis; model weights are not included and no analysis results are preloaded.
